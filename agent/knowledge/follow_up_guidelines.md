# AD/MCI 临床随访与干预建议

## MCI 随访标准（AAN 指南）
- **随访频率**: 每 6-12 个月一次认知评估
- **评估工具**:
  - 首选: MMSE + MoCA + CDR (Clinical Dementia Rating)
  - 补充: ADAS-Cog (临床试验), FAQ (功能评估)
  - 神经精神评估: NPI (Neuropsychiatric Inventory)
- **影像随访**: 每 12-24 个月复查结构 MRI
- **生物标志物**: 条件允许时检测 CSF Aβ42/p-tau 或 Amyloid-PET

## 风险因素管理
- **不可控因素**: 年龄（65岁后每5年风险翻倍）、APOE ε4 基因型（2-3倍风险）、家族史
- **可控因素**:
  - 心血管健康: 控制高血压 (SBP < 140mmHg)、糖尿病 (HbA1c < 7%)
  - 生活方式: 每周≥150分钟中等强度运动、地中海饮食
  - 认知活动: 认知训练、社交参与、学习新技能
  - 听力损失: 听力障碍是最大可干预风险因素，建议听力筛查和助听器
  - 睡眠: 保证7-8小时睡眠，筛查睡眠呼吸暂停
- **Lancet Commission 2024**: 列出了14种可干预的痴呆风险因素

## 药物干预现状
- **FDA批准药物**:
  - 胆碱酯酶抑制剂: 多奈哌齐 (Donepezil)、卡巴拉汀 (Rivastigmine)、加兰他敏 (Galantamine)
  - NMDA受体拮抗剂: 美金刚 (Memantine)
  - 抗淀粉样蛋白单抗: Aducanumab (Aduhelm) - 争议较大; Lecanemab (Leqembi) - 2023年获批; Donanemab (Kisunla) - 2024年获批
- **Lecanemab/Donanemab使用条件**:
  - 必须Amyloid-PET或CSF确认淀粉样蛋白阳性
  - 适用于MCI或轻度AD痴呆阶段
  - 需APOE ε4基因型检测（风险分层）
  - 需定期MRI监测ARIA (Amyloid-Related Imaging Abnormalities)
- **重要提示**: 本系统不提供用药建议，所有药物方案须由专科医师制定

## MCI进展风险预测模型
- **临床模型**: CAIDE风险评分（中年血管风险 + 年龄 + 教育 + APOE）
- **影像模型**: 海马体积 (MRI) + FDG-PET + Amyloid-PET
- **多模态模型**: 临床 + 影像 + 生物标志物 + APOE
- **SA-STGCN模型**: 基于静息态fMRI功能连接，预测4年内MCI向AD转化的风险（本系统核心）

## 安全网建议
- 以下情况建议紧急转诊:
  - 快速进行性认知下降（< 6个月显著恶化）
  - 伴有局灶性神经功能缺损
  - 步态障碍 + 尿失禁 + 认知下降三联征（提示正常压力性脑积水）
  - 年轻起病（< 65岁）
  - 不典型临床表现（如语言障碍为主、视空间障碍为主等）

## 患者与家属教育
- AD是进行性疾病，早发现早干预有助于延缓进展
- 法律与财务规划应尽早（在患者具备决策能力时）
- 照护者负担评估和支持同样重要
- 推荐加入AD家属支持组织

*以上内容基于NIA-AA 2024、AAN实践指南和Lancet Commission 2024编写，仅供参考。*
