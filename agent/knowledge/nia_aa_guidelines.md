# NIA-AA 阿尔茨海默病诊断标准（2024 修订版）

## ATN 生物标志物分类体系

### A - 淀粉样蛋白 (Amyloid)
- **A+**: CSF Aβ42 降低 或 Aβ42/Aβ40 比值降低 或 Amyloid-PET 阳性
- **A-**: 无淀粉样蛋白病理证据
- **临床意义**: A+ 是 AD 的必要不充分条件，可在认知症状前 15-20 年出现

### T - Tau 蛋白 (Tau)
- **T+**: CSF p-tau181 升高 或 p-tau217 升高 或 Tau-PET 阳性
- **T-**: 无 Tau 病理证据
- **临床意义**: T 标志物反映神经纤维缠结负担，与认知下降速率密切相关

### N - 神经退行性变 (Neurodegeneration)
- **N+**: MRI 海马萎缩 或 FDG-PET 颞顶代谢降低 或 CSF t-tau 升高
- **N-**: 无神经退行性变证据
- **临床意义**: N 标志物反映不可逆神经元损伤程度

## MCI 诊断标准（Petersen 标准）
1. 患者或知情者报告的记忆减退
2. 客观认知功能损害（低于年龄/教育匹配常模 1-1.5 SD）
3. 基本日常生活能力保留
4. 未达到痴呆诊断标准
5. MMSE 分数通常在 24-27 之间

## AD 痴呆诊断标准（NIA-AA 2024）
1. 符合痴呆诊断标准（认知损害影响日常生活）
2. 隐袭起病，渐进性恶化
3. 典型表现：情景记忆损害为主
4. 排除其他病因（血管性、Lewy体、额颞叶等）
5. 生物标志物支持：A+T+ 即可确诊 AD

## MCI 进展风险分层
- **低风险**: MCI + A-T-N- 或 仅A+ → 年转化率 < 5%
- **中风险**: MCI + A+T+N- → 年转化率 10-20%
- **高风险**: MCI + A+T+N+ → 年转化率 20-40%

## 轻度认知障碍 (MCI) 的临床亚型
- **遗忘型 MCI (aMCI)**: 以记忆损害为主，最可能进展为 AD
- **非遗忘型 MCI (naMCI)**: 以其他认知领域损害为主（执行功能、语言、视空间）
- **单领域 vs 多领域**: 多领域 MCI 进展风险更高

## 诊断建议
- 推荐对所有 MCI 患者进行结构 MRI 检查（I 级证据，A 级推荐）
- 条件允许时进行 Amyloid-PET 或 CSF 检查
- APOE ε4 基因型是重要风险因素，但不作为独立诊断标准
- 建议每 6-12 个月进行认知随访评估
